мы будем разрабатывать учебную среду для помощи в изучении техник 3d графики. Нам необходимо разделить проект на модули, чтобы в последствии можно было работать с ними отдельно.
- модуль UI - будем совершенствовать поэтапно;
- модуль вычисления перспективной проекции точек на экран
- модуль для отображения точек трёхмерной сцены на экране
- модуль для отображения сетки каркаса
- модуль для отображения триангулярной поверхности с удалением невидимых треугольников посредством нормали и сортировки
- модуль рендеринга посредством прохода лучей
- модуль для отображения фигур со сплошной поверхностью, заданной математически
- модуль отображения воксельной сцены
- модули генерации трёхмерных объектов
- модуль генерации ландшафтов
